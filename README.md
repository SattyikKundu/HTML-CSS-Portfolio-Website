## II. Notable Features Summary:
- The header menu is a ***floating*** menu that always sticks to the top of viewport whenever you scroll up or down.
- The first 3 links in the header menu (`About`, `Projects`, and `Skills`) use anchor links that *smoothly* scroll to the corresponding section. Also, the Contact link navigates to `contact.html` as intended. 
- Responsive design CSS was added to make the website adjust the location of various components, such as images and buttons, so the layout remains usable on mobile devices. I tested the responsiveness across several common viewport widths, including 320px, 360px, 480px, 540px, and 720px, and etc.

## III. What I Learned and Practiced for this Portfolio Project
- I put heavy focus on mastering my HTML and CSS skills since they're still foundationally important for webpage structures and visual design, even in more advanced applications that also use technologies like JavaScript, React, PostgreSQL database, and more.
- <ins>As demonstrated earlier, I learned and applied many CSS styling techniques throughout the project including</ins>:
  - Adding seamless image pattern to the background
  - Creating a floating header menu that remains accessible whilst scrolling.
  - Implementing and refining my responsive design to remaing visually appealing across different mobile viewport sizes. Browser developer tools were especially helpful for testing this. 
  - Using a nested horizontal scroller to fit a large image under Project #1 in the `Featured Projects` section.
  - Importing external resources such as Google Fonts and technology icons.
  - Creating, styling and linking buttons.
